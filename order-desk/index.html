What we fixed after our last review

Three critical credibility and engineering issues, addressed before this build shipped.

Markup ≠ Margin

Most factory Excel sheets label "20% markup" as "margin" — but 20% markup = 16.67% gross margin (or less after agent commission). Our engine shows both. Every quote displays Markup 20.0% · Gross Margin 15.75% explicitly.

"Verified Quote" on fake data — gone

Removed the "Verified Quote" badge. Every demo surface carries a persistent SAMPLE DATA ribbon. Zara / H&M / Nike names are replaced with Buyer A / B / C. No unverifiable metrics on this site.

Money math moved to the server

All financial calculations now run server-side in a versioned deterministic engine (v1.0.0) with 32 unit tests. The browser never does money math. Old quotes reproduce under their original formula version. AI cannot set prices.
