Demo

Ask a handbook. Get the passage.

This is the studio's Knowledge Search & Retrieval system, small enough to run in a page: a question box over one company handbook. Answers cite the exact passage — and when the answer is not in the documents, it says so.

Fictional company — demo data Citations you can click Refuses what it cannot source

Northwind Supplies Ltd. is a fictional company. Every document below was written for this demo — none of it is real client data.

How this runs: the language model sits behind a serverless function — the API key never reaches this page. The endpoint is rate-limited (10 questions per minute) and logs nothing about visitors: no IP, no user agent, no questions. The last suggested question is deliberately not in the handbook — try it.

The documents

The handbook it answers from.

Three short documents, thirteen passages — fictional demo data. Click any citation in an answer to jump to the passage it quotes.

Same behaviour on your handbook, policies and drive — scoped in a written plan, evaluated on your real questions, handed over completely.
