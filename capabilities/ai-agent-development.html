For technical evaluators

Under the hood.

Architecture, evaluation and operations — the engineering substance behind the offer. Final choices are set per engagement, in the written scope.

Architecture

  • Orchestration. Deterministic step sequences with explicit fallbacks around model calls — not free-roaming loops.
  • Tool discipline. Every tool call is schema-validated and permission-scoped; least privilege by default.
  • Audit state. Full state and transcript persisted per run, so any action can be reconstructed after the fact.

Evaluation & acceptance

  • Task-level acceptance. A defined set of real tasks with expected outcomes, scored end to end — agreed in the written scope.
  • Escalation correctness. When the agent must stop and hand to a human is tested as rigorously as what it does.

Operations

  • Run traces. Per-step latency and cost on every run, on a dashboard.
  • Controls. Kill switch, step-level approval for sensitive actions, budget caps per run.
  • Failure behavior. Failed runs replay deterministically for debugging — no he-said-she-said with a log file.

Scope

What the engagement covers.

In scope

  • Agent architecture: goals, tools, permissions, escalation
  • Tool and API connections into your existing systems
  • Evaluation harness against your real cases
  • Observability: logs, traces, and action history
  • Human handoff and approval gates
  • Deployment on infrastructure you choose

Not included

  • ×Unsupervised actions on sensitive operations
  • ×Access to systems outside the agreed tool list
  • ×Ongoing model research or novel algorithm work
  • ×Marketing claims of full autonomy — the agent does scoped work

FAQ

Asked about this capability.

How do you stop an agent doing something stupid?

Boundaries are designed, not hoped for: explicit tool permissions, approval gates on sensitive actions, and evaluation against your failure cases before anything runs unattended.

Which agent frameworks do you use?

Whatever fits the job — the framework is an implementation detail we justify in the design doc, not a religion.

How is this priced?

As a scoped engagement. After a short discovery we write the scope and quote; nothing is charged before you approve it in writing.
